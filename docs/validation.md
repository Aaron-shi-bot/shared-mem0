# 验证记录与适用范围

本文描述 2026.10.21.2 在公开前完成的验证。历史验收使用私人项目语料，公开仓库不包含这些记忆、原始会话、设备身份、云端链接或验收数据库。公开源码中的合成用例可用于回归；它们不能代替真实使用验证。

## 真实项目检索回归

固定 470 条记录、同一向量模型，使用 16 个已知的真实项目问题比较升级前后结果：

| 阶段 | 第一条命中 | 前三条命中 | 说明 |
| --- | ---: | ---: | --- |
| 升级前 | 9/16 | 12/16 | 原有长记录向量检索与排序 |
| 替换检索实现，保持语料不变 | 14/16 | 15/16 | 完整分段、关键词与语义匹配、角色排序 |
| 补齐有证据的新旧决定关系后，正式服务验收 | 15/16 | 15/16 | 同时包含程序改善与内容整理效果 |

尚未命中的一个普通项目搜索问题把目标排在第 5；使用项目与精确任务交接一起查询后，目标排在第 1。不能据此把一般项目检索写成全部命中。

这组问题参与了开发和调优，属于小样本、非盲测回归；不是独立随机抽样，也没有给出置信区间。`15/16` 不能推广为整体检索准确率。生命周期整理后的结果与只换算法的结果分开列出，避免把语料修正算作纯算法收益。

## 长记录完整性

升级审计发现原模型 tokenizer 上限为 128 token，多数已有记录超过这一长度。新增分段索引后，正式验收数据为 474 条原记录、5,464 个片段，最大实际片段为 99 token，均低于模型上限。

切换前已有记录的 ID 和文本保留；之后的新记录与生命周期关系属于明确的内容维护操作。检索缓存不替代原始记录，重新生成缓存也不应改写记忆文本。

这些数字对应当时的私人验收快照，不是仓库初始化后应有的数据量。

## 自动回归与其他设备快照

公开前的升级环境中，13 项新增回归和 73 项原有回归通过。覆盖检索切分、范围隔离、生命周期、备份、会话变化与重试等逻辑。仓库中的测试入口及依赖以当前文件为准；这些历史通过数不代表任何电脑上安装后自动全部通过。

另外，使用另一设备的一份真实云快照，在本机隔离服务中进行了 14 项 HTTP 接续验收，全部通过。快照包含 205 条记录，其中 199 条当前有效、6 条已被替代。验收包含来源隔离、版本保护、重复内容处理和预览后变更防护。

这是“真实其他设备数据 + 本机隔离服务”的验收；尚未完成两台实体电脑安装新版后的长期往返接续测试。

## 可以如何复验

安装锁定依赖后，在仓库根目录运行公开回归：

```powershell
.\venv\Scripts\python.exe -B -m unittest discover -s scripts -p "test_*.py" -q
```

公开检索测试使用合成文本与测试 tokenizer，不需要下载向量模型，也不读取私人记忆。回归数据与客户端配置检查使用隔离的临时目录；这类逻辑检查不能替代真实向量模型、已安装客户端或两台实体电脑上的验证。

### 本次公开发布的短检查

2026-10-21 在公开源码目录完成发布前短检查：Python 3.13 语法解析通过；公开回归命令执行 152 个测试实例全部通过（其中包含导入和继承带来的重复执行，不代表 152 个独立场景）；初始化、重复初始化不覆盖已有密钥、参数冲突检查，以及临时客户端配置自检通过。新模型下载入口已作代码检查，未重新下载模型或执行新的长期现场测试。公开文件检查未发现私人部署标识或真实凭据；脱敏测试保留明确标为 SYNTHETIC 的无效样例。

请使用单独的测试数据目录和端口，避免指向现有私人数据库。最先检查：

- 新安装能否完成模型缓存准备，并在状态中显示引擎、检索索引就绪。
- 保存包含唯一尾部关键词的长记录后，能否通过尾部内容找到原记录并读取完整文本。
- 两个项目与两个任务的近似文本能否隔离检索；明确替代后默认结果是否排除旧决定、历史查询是否仍可读。
- 导入合成设备快照前是否有差异预览，重复采用是否稳定，旧快照与过期预览是否被拒绝。
- 生成的 ZIP 能否预览和恢复，原文、ID、来源和替代关系是否保留。
- 启用会话整理时，源文件变化、任务失败和租约过期能否保持待处理状态，是否错误地把助手报告当作用户决定。

启动新的真实使用验证之前，另行确认客户端版本、目录映射和稳定项目 ID。公开时暂缓长期双设备验证，因此这里不记录未经执行的结果，也不承诺连续运行可靠性。

## 尚未验证或存在的边界

- 代码最低版本为 Python 3.11，但锁定依赖尚未逐个 Python 版本安装验证；原运行环境为 Windows、Python 3.13.0 64 位。
- 多天、多项目、两台实体电脑并行工作后的接续准确性。
- Linux、macOS 及各个客户端全部版本的完整安装和运行。
- 不可信用户隔离、公开网络部署和大规模并发。
- 对所有会话格式、所有凭据形式的完整识别和脱敏。
- 自动冲突解决、无人工确认的双向实时同步。
- 大语料规模的性能、独立盲测的召回率和错误率。

已通过的单机回归、快照校验和小样本检索改善只能支持各自覆盖的结论。历史记忆是否正确、是否仍然有效，仍需要结合来源、当前项目状态与使用者确认判断。
